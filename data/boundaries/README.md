# Berkeley police beat boundaries

Source: City of Berkeley, Portal_CommSvcs MapServer, layer 15 (Police Beats).
Downloaded November 22, 2026 using the [GeoJSON query](https://gis.cityofberkeley.info/arcgis3/rest/services/Public/Portal_CommSvcs/MapServer/15/query?where=1%3D1&outFields=*&outSR=4326&f=geojson).
Coordinates are longitude and latitude (EPSG:4326). Sector identifies the beat.
A5 applies this fixed geography to both 2024 and 2025. Historical boundary
versions and time-of-day patrol assignments have not been verified.
